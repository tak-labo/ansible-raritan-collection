tak_55.raritan_xerus Release Notes

.. contents:: Topics

v1.0.0
======

New Modules
-----------

- ``tak_55.raritan_xerus.pdu_config`` - Configure PDU-wide settings (name, startup state, cycle delay)
- ``tak_55.raritan_xerus.outlet_config`` - Configure outlet settings and control power state (on/off/cycle)
- ``tak_55.raritan_xerus.snmp_config`` - Configure SNMP v2/v3 settings and system information
- ``tak_55.raritan_xerus.syslog_action`` - Manage syslog event engine actions
- ``tak_55.raritan_xerus.snmp_trap_action`` - Manage SNMP trap event engine actions
- ``tak_55.raritan_xerus.event_rule`` - Manage event engine rules
- ``tak_55.raritan_xerus.user_account`` - Manage user accounts and SNMPv3 settings
- ``tak_55.raritan_xerus.dns_config`` - Configure DNS servers and search suffixes
- ``tak_55.raritan_xerus.datetime_config`` - Configure NTP servers and timezone
- ``tak_55.raritan_xerus.pdu_facts`` - Gather PDU metadata, inlet and outlet sensor readings
